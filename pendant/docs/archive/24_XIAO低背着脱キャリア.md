# XIAO低背・着脱キャリア案

> 2026-10-15: この案の目的（SIG と認証の固定費を避ける）は、調査では日本以外で成り立たない可能性が高い。販売形態は保留（[48](./48_前提の確定_2026-10-14.md) R1）。厳しい理由と生かせる条件は [49](./49_XIAOキット案が厳しい理由.md)。

## 目的

初期販売フェーズでは、Bluetooth SIGの高額なProduct Qualification固定費を需要検証前に負担しないため、**Seeed Studio XIAO nRF54L15を未改造・未書込みの別部品として同梱し、ユーザー側で組み立て・FW書込みを行うキット構成**を候補とする。

その際の機械設計上の主要課題は、通常の2.54 mmピンヘッダ＋メスソケットでは厚みが増えすぎること。ペンダント用途では、XIAO着脱機構による追加厚みを概ね **2〜3 mm以内** に抑えたい。

対象SKUは **Standard**（CR2477・smartphone-required、[22](./22_製品バリエーション_Standard_Premium.md)）。XIAOは無改造のため3.3 V系で動き、キャリア側の1.8 V周辺部品とはレベル変換で接続する（[25](./25_XIAO無改造とレベル変換コスト.md)）。

本案では、XIAOをキャリアPCB上に積層せず、**キャリアPCBの切り欠きへ落とし込み、XIAO側面のキャスタレーション（金メッキされた半穴端子）へ横方向からSMTスプリングコンタクトを当てる**構造を第一候補とする。

## 基本構造

### 上面イメージ

```text
carrier PCB

──────────────┐      ┌──────────────
              │      │
   spring  →  │ XIAO │  ← spring
   contacts   │      │     contacts
              │      │
──────────────┘      └──────────────

          USB-C → ケース側面
```

### 断面イメージ

```text
        XIAO PCB
        ─────────────
       ← spring contact
carrier ───┐      ┌─── carrier
           └──────┘
            cutout
```

XIAO PCBとcarrier PCBをほぼ同一面に置くことで、通常のドーターボード積層のように

`carrier PCB + socket + XIAO PCB`

の厚みを単純加算しない。

## 機能分担

### XY位置決め

**電気接点には位置決めを担当させない。**

- carrier PCBの切り欠き形状
- 必要ならケース内の樹脂リブ

でXIAOのXY位置を決める。

### Z方向保持

- ケース上蓋のリブ
- スナップ爪
- 薄いエラストマーパッド

などでXIAOを押さえる。

スプリングコンタクトだけで機械保持すると、接触圧・摩耗・公差が機械強度と電気信頼性の両方に影響するため避ける。

### 電気接続

XIAO左右のキャスタレーションへ、carrier PCBにSMT実装した **side-contact spring / spring finger** を横方向から接触させる。

XIAO本体には

- ピンヘッダ
- はんだ付け
- 改造

を要求しない。

現時点の具体候補。

- SMT実装
- side contact用途
- 高さ：約1.0 mm
- 幅：約0.8 mm
- 長さ：約3.6 mm
- 接触抵抗：30 mΩ以下
- 定格電流：1.5 A
- 挿抜耐久：10回クラス

参考：
https://www.smk.co.jp/ja/newsroom/press-release-product/2022/1151cs

今回のキット用途では、開発治具のように数百回挿抜する必要はなく、ユーザーが初回組立時に1回、保守時に数回抜き差しする程度を想定するため、10回クラスでも候補になり得る。

MTCにも、plug-in moduleの**側面接触**を明示したSMD spring製品群がある。

参考：
https://www.mtc.de/en/media/news/side-contacting-smd-springs

- 接触ストローク
- 初期荷重 / 最大荷重
- 接触位置公差
- Au plating仕様
- 挿抜寿命
- リール供給可否
- 単価
- 日本での調達性

## XIAO側条件

XIAOフォームファクタは約 **21 × 17.8 mm**、左右に2.54 mmピッチのキャスタレーション端子を持つ。

Seeed XIAO series:
https://www.seeedstudio.com/xiao-series-page

初期試作ではXIAO nRF54L15 SenseをFW開発に使えるが、キット同梱版ではSense機能を使わない場合、通常版XIAO nRF54L15を優先する。

**USB-Cはケース外へ出さない**（防水とUXの割り切り。AirTagのように閉じた円盤として扱う）。USB-Cを使うのは **XIAOをキャリアへ載せる前** のFW書込みとBLE初期設定だけ。

- 通常のFW更新はBLE DFU
- BLE DFU失敗時の復旧・再書込みは、ケースを開けてXIAOを取り外して行う（保守作業扱い）
- ケース側にUSB開口・USB用シールは設けない

したがって、XIAOのUSB-C側はケース内壁で受けるだけでよく、外部アクセスの配置制約は不要。代わりに、着脱は初回組立 + 保守で数回に限られる前提が接点寿命（10回クラス）に直結する。

## 初期販売キットとの関係

想定構成：

```text
lifeOS Pendant Kit
├─ carrier PCB
├─ ケース
├─ 電源系 / ストレージ / マイク等
└─ 別袋：genuine Seeed Studio XIAO nRF54L15
     └─ 未改造・未書込み

ユーザー作業（**電池装着より前にUSBを終える。電池を付けたままUSBを挿す手順は存在させない**）：
1. XIAO単体をUSB-Cでスマホ（またはPC）へ接続
2. lifeOS FWを書込み、BLEの初期設定を行う
3. USBを抜く
4. XIAOをcarrierへ装着
5. 電池を装着
6. ケースを閉じる
```

これにより、USB給電・XIAO内蔵充電ICと一次電池（CR2477）が同時に接続される状態を手順上なくす。**XIAO裏面の電池パッドにCR2477を接続しない**（Li-ion向け充電IC SGM40567の経路で、一次電池を充電しうる）。CR2477は5Vピン（VBUS）経由のみで給電する（[25](./25_XIAO無改造とレベル変換コスト.md)）。書込み手段（スマホ経由かPC経由か）は未確定。

FWは当方で開発・配布するが、XIAOへの書込みは購入者側で行う方針を候補とする。

Bluetooth qualificationの扱いは商品構成・ブランド表示・同梱方法・FW提供方法まで含めて判断されるため、販売前にBluetooth SIGへ構成図を提示して書面確認を取る。

Bluetooth SIG qualification guidance:
https://qualification.support.bluetooth.com/hc/en-us/articles/26704450972813-Do-I-Need-to-Qualify

## 採用理由

通常のピンヘッダ方式に対する利点：

- XIAO側のはんだ付け不要
- ユーザー組立が容易
- XIAOを独立したSeeed製品のまま扱いやすい
- 組立前にXIAO単体でUSB-Cから書込み・初期設定できる
- carrier PCBへの積層を避けられる
- 接点高さ1 mm級を狙える
- ペンダント全厚の増加を2〜3 mm以内へ抑えやすい

Solder PartyのFlexyPin / SP039もキャスタレーションへ着脱接続する先行例として参考になるが、今回の量産キャリアでは**PCB切り欠き + SMT side spring + ケース保持**の方が低背化とユーザー組立性に適すると考える。

FlexyPin reference:
https://www.solder.party/docs/flexypin/

## リスク / 未確定事項

1. **XIAOキャスタレーション側面へ確実に接触できるか**
   - springの接触点高さとXIAO PCB厚の公差を実測する。

2. **14接点の合計横荷重**
   - 左右7個の反力が大きすぎると挿入力が高くなる。
   - 左右対称にしてXIAOへ曲げモーメントを与えない。

3. **挿抜寿命**
   - 初期販売キットなら10回程度でも成立し得るが、開発用途では別治具を使う。

4. **接触抵抗 / 酸化 / 汗環境**
   - Au plated接点を優先。
   - 最終ケースでは汗・結露が接点へ到達しない構造にする。

5. **アンテナkeep-out**
   - XIAOアンテナ周辺のcarrier copper、電池、NAND、ケース金属部品を避ける。
   - 切り欠き構造がRF性能を劣化させないことを実機RSSI/throughputで確認する。

6. **電圧系統・待機電力**
   - XIAOは無改造で3.3 V系。1.8 V周辺部品（T5838・NOR・RTC）との間にレベル変換が必要。
   - 5 Vピン（VBUS）から給電する場合のTPS628438のdropout、変換ICの静止電流、床電流の合計をCR2477の約1年目標に照らして評価する（[25](./25_XIAO無改造とレベル変換コスト.md)）。

7. **側面接点は14本まで、GPIOは足りるか**
   - 側面の14接点は D0〜D10（GPIO 11本）+ 5V・GND・3V3。必要なGPIOはマイク4（PDM CLK/DIN、THSEL、WAKE）+ NOR 4 + RTC 2（I²C）+ 前面ボタン1 = 11本で、**ちょうど収まる（余裕0）**。
   - [23](./23_試作計画_Phase0_1.md) のイベントマーカー（D6）はデバッグ用なので、キット版では外す。残すと12本になり足りない。
   - 余裕がないため、GPIOを増やす変更（変換ICのDIR/OE制御、RTC割込など）は入れない。必要なら THSEL を抵抗で固定して1本空ける案（T5838の仕様確認が必要）。
   - 23の逃げ道（裏面パッドD13〜D15をワイヤで出す）はこの構造では使えない。
   - 詳細は #21。

8. **技適**
   - 取得済みとの情報あり（2026-10-13にユーザーが提示）：工事設計認証番号 217-252398、2025-07-24、認証を受けた者 Seeed Technology Co., Ltd.、対象は XIAO nRF54L15 / Sense、2402〜2480 MHz。
   - **独立検証は未了。** 総務省の検索ページは自動取得で403、Seeed wiki・Switch Scienceの商品ページには記載なし。
   - 販売前に総務省の技適検索で原本（番号・型式・認証者）を確認し、画面を証跡として保存する。無改造・未書込みのXIAOを別部品で同梱する構成なら、認証対象の無線部は改変しない。

（USB-Cはケース外へ出さないため、USB挿抜力がspring contactsへ掛かる問題は初回組立前のXIAO単体作業に限られ、キャリア側の機械荷重としては扱わない。）

## 次の検証

1. XIAO nRF54L15実機の外形・PCB厚・castellation位置を実測。
2. 候補spring contactを少数購入。
3. 2層carrier試験基板を作成。
4. XY位置決めはPCB切り欠き、Z保持は3Dプリント治具で検証。
5. 全14接点について接触抵抗・振動・着脱時の瞬断を確認。
6. BLE RSSI / throughputをXIAO単体とcarrier装着時で比較。
7. 成立後、量産carrier PCBとケースへ統合。

## 暫定結論

初期キット版のXIAO接続方式は、**「carrier PCB切り欠きへXIAOを落とし込み、左右キャスタレーションへ1 mm級SMT side-contact springを当て、ケース側で機械保持する」**案を第一候補とする。

これにより、XIAOを未改造・着脱可能なまま、通常のピンヘッダ方式より大幅に低背化できる。USB-Cは組立前のXIAO単体作業に使い、ケース外へは出さない。
