# XIAO無改造 + 1.8 V周辺部品 — レベル変換のコスト調査

> 2026-10-14: 周辺部品の NOR は 1.8 V 生 SPI NAND に置き換えた（[22 §3.3](./22_製品バリエーション_Standard_Premium.md)）。1.8 V 側・SPI 4 本という前提は同じ。

## 1. 前提と問い

- 周辺部品（T5838・NOR・RV-3032）は **1.8 V構成を維持する**（18・19・22）。
- キット版は **XIAO nRF54L15を無改造** で使う（[24](../docs/archive/24_XIAO低背着脱キャリア.md)）。[23](../docs/plan/prototype.md) §3.1 のL1撤去による1.8 V化はキットではできない。
- したがって nRFは3.3 V系、周辺は1.8 V系になり、間に **レベル変換を入れる**。

問い: レベル変換を入れるコスト（BOM・面積・電力・電圧追従）は許容できるか。

---

## 2. 確認できた事実（XIAO側）

出典は Seeed公式の回路図PDF（nRF54L15版）と wiki。

| 項目 | 内容 |
|---|---|
| nRF VDD | `VSYS_3V3` = TPS628438（U5）の出力。1 µH（L1）経由 |
| U5の入力 | `VBUS` ネット。Q1（LP0404N3T5G）がUSB無しのときVBATをVBUSへ通す |
| 3V3ピン | `3V3_OUT`（出力）。wikiも「Power Output」 |
| 5Vピン | `VBUS`（入出力）。キットで側面接点から給電できるのはここ |
| 電池パッド | 裏面。wikiは3.7 V級Li-ionを推奨。充電IC SGM40567付き。**CR2477は接続しない**（一次電池を充電しうる） |
| USB側 | SAMD11用LDO（SGM2040）は `TYPE-C_5V` 入力。**USBを抜けば止まる** |
| UM3301 | `VSYS_3V3` と `SAMD11_3V3` をつなぐ変換IC |

→ キットでは **CR2477 → 5Vピン → U5 → 3.3 V系** が給電経路になる（Phase 0の5 Vピン給電と同じ。[23](../docs/plan/prototype.md) §2）。

### 電池電圧との関係（重要）

TPS628438は降圧のみ。CR2477（約3.0 V → 終端近傍2 V級）では **常にdropout**（入力 ≒ 出力）で、`VSYS_3V3` は3.3 Vにならず **電池電圧に追従して下がる**。

- nRF VDDは固定3.3 Vではなく、電池消耗とともに下がる。
- レベル変換ICのXIAO側電源（VCCx）は **3V3ピンへつなぎ、追従する前提** にする。固定3.3 Vを仮定しない。
- 電池終端近傍で変換IC・nRFが動く下限電圧がシステムの動作下限を決める（nRFのVDD下限はデータシートで確認する）。

### 未確認・不確かな情報

- フォーラムの報告では、3V3ピンへ外部給電すると約450 µA流れた（backfeedの可能性）。公式の確認ではない。**3V3ピンへ給電する案は採らない**。
- コイン電池付近でU5のIqが増えるとの報告もあるが、実測値は未確認。**Phase 0で測る**（23 §2）。

## 3. 信号と方向

[23](../docs/plan/prototype.md) §3.1 のピン割当から（イベントマーカーD6はデバッグ用なので除く）。

| 信号 | 方向（nRF視点） | 種別 |
|---|---|---|
| PDM CLK | 出力 | push-pull |
| PDM DIN | 入力 | push-pull |
| THSEL | 出力 | push-pull |
| WAKE | 入力 | push-pull |
| NOR SCK / MOSI / CS | 出力 | push-pull |
| NOR MISO | 入力 | push-pull |
| I²C SDA / SCL | 双方向 | open-drain |

- 方向固定のpush-pull 8本と、open-drain 2本。
- **変換は上下両方向が必要。** 3.3 V系のnRFは入力HIGHを0.7×VDD前後で見る（データシートで確認）。1.8 V出力ではVDDが高いほど認識できず、上げ変換が要る。
- I²Cは「nRFがLowを引くだけ」なら下げ変換不要に見えるが、**読出し側のHIGH判定が1.8 Vで通らない**ので変換が要る。

## 4. 候補部品とコスト

価格は検索結果（DigiKey地域ページ）と製品ページの値。**最終見積は実発注先（JLCPCB等）で取り直す**。

| 部品 | 用途 | 電源範囲 | 静止電流（max） | 価格の目安 |
|---|---|---|---|---|
| SN74AXC4T245（TI） | push-pull 方向固定 | 両側 0.65〜3.6 V | 0.04 mA = 125 ℃ の max（両電源合計。85 ℃ で 20 µA、typ 未公表。[37](./37_レベル変換IC比較.md)） | $0.87（1個）→ $0.44（500）→ $0.41（2,000リール）。在庫は12週待ち表示 |
| TXS0102（TI） | I²C（open-drain 2ch） | A側 1.65〜3.6 V、**B側 2.3〜5.5 V** | 0.025 mA（製品ページ） | 未確認（要見積） |

- push-pull 8本は4bit×2組のDIR制御で、方向（出力5/入力3）の組み合わせから **4bit品が3個** 前後になる。8bit品を使えば減らせるが、方向グループの切り分けが別途要る。
- **TXS0102のB側は2.3 V以上。** nRF側電源（電池追従）が電池終端近傍で2.3 Vを割ると動かなくなる。I²Cには電源範囲が広い別の方式（ディスクリートFET型など）も候補。
- SN74AXC4T245は電源範囲が広く、電池追従に向く。在庫・納期は要確認。

### BOM増の概算

- 4bit品×3 + I²C×1。**1台あたり概ね$2〜3.5**（上表の価格帯から。TXS0102は価格未確認のため仮置き）。
- 面積は各数mm角（UQFN 2.6×1.8 mmなど）で、キャリア上では小さいが、配線と電源デカップリングが増える。

## 5. 電力への影響

本件の本質はBOMより **待機電力**。Standardの目標は約1年（22）で、CR2477を3 Wh、`p ≈ 0.4` として **平均約0.34 mW（3 Vで約114 µA）**。3 Whは公称値の単純計算で、終端2.0 V・内部抵抗・自己放電・低温は含まない（再計算は Issue #17）。

- 変換IC: 製品ページの静止電流maxは1個あたり数十µA。3個で最大100 µA級になり得るが、**これはmaxであり、実機は桁違いに低い可能性が高い**。データシートのtypicalとOE制御（出力停止時の電流）、実測で確認する。
- XIAO側の床電流（U5のdropoutとIq、UM3301・RFスイッチのリーク、nRFのVDD高電圧運転）は **キャリアの変換ICより大きい可能性** がある。
- nRFが3.3 V系（電池追従）で動くことによるBLE・CPU電流の増加は、1.8 V運転との差として [18](../docs/archive/18_ストレージ再検討_1.8V面積電力コスト.md)・[19](../docs/spec/power.md) の前提から外れる。要実測。

## 6. 比較

| 案 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| A（採用方向） | 無改造XIAO + 周辺1.8 V + レベル変換 | 1.8 V構成を維持。XIAOは別部品のまま | BOM増、変換IC静止電流、電池追従への対応 |
| B | L1を外して1.8 V化（23の改造） | 変換不要 | キットでは不可（無改造・未書込みという前提に反する） |
| C | 周辺も3.3 V系に寄せる | 変換不要 | 1.8 V構成の撤回。NOR・マイクの電源範囲と電力の再評価が必要 |
| D | Phase 4のチップ直載せで1.8 V化 | 変換も改造も不要 | キット版（XIAO同梱）の目的に合わない。量産期の話 |

Aを前提にし、Cは「変換コストが電力・BOMで許容できなかった場合の戻り先」として残す。

## 7. 次にやること

1. **Phase 0でXIAO無改造の床電流を測る**（5 Vピン給電、電池追従の電圧範囲を含む。23 §2）。
2. SN74AXC4T245のデータシート（SCES877B）のtypical ICC・OE時電流を確認。
3. I²C変換方式を確定（TXS0102の電源下限が電池終端と両立するか）。
4. 実発注先（JLCPCB等）の部品価格・在庫を取り、BOM増を確定。
5. キャリア（Phase 1相当）に変換ICを載せ、変換あり/なしで周辺電流と合計電流を比較。

> **更新（2026-10-14、issue #22）**: 比較と決定は [37](./37_レベル変換IC比較.md)。push-pull は TXU0204 + TXU0304 の 2 個（ICC 最大 2.5 µA、25 ℃）、I²C は RV-3032 を 3V3 側のレールに置いて変換を無くす案。TXS0102 は電池終端と衝突するため採らない。
