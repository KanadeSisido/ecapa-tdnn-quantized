# 37. レベル変換 IC の絞り込み — ICC・電源下限・個数・価格（キット版）

Status: **DRAFT（2026-10-14、issue #22）。** TI データシート本文（SCES877B、SCES935A、TXS0102）と RV-3032 のデータシートから値を取った。価格・在庫は Web 検索の断片で、**最終見積は JLCPCB / LCSC で取り直す**（#23）。

## 1. 結論

1. **push-pull 8 本は TXU0204 + TXU0304 の 2 個で済む**（5 本 = nRF→周辺、3 本 = 周辺→nRF。0204 は 2+2、0304 は 3+1 の固定方向）。DIR 端子が無く、OE を電源へ固定するので GPIO を使わない。**ICC は最大 2.5 µA（25 ℃）/ 6 µA（125 ℃）で、SN74AXC4T245 ×3（最大 60 µA、85 ℃）より 1 桁低い。**
2. **I²C は変換 IC を使わない。RV-3032 を nRF 側（XIAO の 3V3 ピン = 電池追従）のレールに置く。** RV-3032 は VDD 1.4〜5.5 V で、消費は 160 nA（1.3 / 3.0 / 5.0 V でほぼ同じ）なので、電圧が高い側に置いても電力は増えない。I²C の変換が丸ごと不要になる（BOM・面積・漏れ電流が 0）。
3. **TXS0102 は採らない**（B 側 2.3 V 以上、電池終端と衝突）。SN74AXC4T245 は **予備案**（速度と在庫が優位、ICC と個数が劣る）。
4. **BOM 増は約 $1.7 / 台**（TXU 2 個、JLCPCB の 1 個価格、2026-10-14。[42](../docs/archive/42_JLCPCB部品在庫と単価_Phase1.md)）。AXC ×3 は約 $5.1（RSV 型、同）。量産リールでは下がる見込みだが未確認。
5. **Phase 1 のキャリアには変換 IC が要らない**（XIAO の L1 を外して 3V3 に 1.8 V を入れる 23 の構成）。本書はキット版（無改造の XIAO）の話。

## 2. 前提（25、36 と同じ）

- XIAO 側（nRF）の電源は U5（TPS628438）の出力 = 3V3 ピンで、**電池電圧に追従する**。TPS628438 は VIN 1.8〜5.5 V、**100 % モードで HS の RDSON が 170 mΩ（typ）/ 260 mΩ（max）**（VIN 3.6 V、300 mA）、UVLO は上昇 1.75〜1.8 V / 下降 1.65〜1.7 V。CR2477 の 3.0 V → 2.0 V 級では常に dropout で、3V3 ≒ 電池電圧 − 負荷 × 約 0.2〜0.3 Ω（インダクタの DCR を含めた粗い見積り、10 mA で約 3 mV）。
- 周辺側は 1.8 V（NOR が 1.7〜1.95 V、25）。したがって **低い側 = 1.8 V 固定、高い側 = 電池追従（概ね 3.0〜2.0 V）**。
- 電池の使用範囲は 30 の段階（NORMAL 2.60 V 以上 / UV の 2.60 / 2.40 / 2.25 V は仮置き）。**終端の判定は 2.0 V（仮定）で行う**。
- 信号（36 §3 の割当）: nRF→周辺（出力 5）= PDM CLK、THSEL、NOR SCK / MOSI / CS。周辺→nRF（入力 3）= PDM DIN、WAKE、NOR MISO。I²C 2 本（RTC）。
- GPIO は余裕 0（36）。**DIR / OE の制御に GPIO を使えない**。電源か GND への固定だけが許される。

## 4. 電力への影響

- Standard の平均電力は約 0.34 mW = 3 V で約 114 µA（25 §5、22）。
- **最悪値で比べる**: AXC ×3 = 最大 60 µA（85 ℃）で平均の約 53 %。TXU ×2 = 最大 5 µA（25 ℃、2 個）〜 12 µA（125 ℃）で約 4〜10 %。**どちらも実測は max より低いはずだが、AXC の typ は公表されていない**ので、AXC を採るなら実測してから。
- OE は固定で有効（GPIO を使えない）。**変換 IC を完全に止める手段が無い**ので、ICC は常に載る。nRF が System OFF に落ちても残る。
- 入力が浮く問題はない（nRF の出力ピンは OFF 時 Hi-Z だが、周辺 IC の入力側に pull を置く規則は 36 / 25 で別途。**Hi-Z の線が変換 IC の入力へつながると中間電位で ICC が増える**ので、nRF → 周辺の信号には **周辺側 / 変換 IC の入力に 1 MΩ 級のプルダウン / プルアップ**を置く。TXU の Schmitt 入力は有利）。

## 5. I²C の方式の決定

**案: RV-3032 を nRF 側（3V3 ピン）のレールに置く。**

- RV-3032: VDD 1.4〜5.5 V（I²C 動作）/ 1.3〜5.5 V（時計のみ）、IDD 160 nA（VDD 1.3 / 3.0 / 5.0 V、25 ℃）、EEPROM 書き込み時のみ 1.6 V 以上。**電池終端 2.0 V でも全機能が使える**。
- 3V3 ピンの負荷は 160 nA + I²C のプルアップだけ。XIAO の U5 は nRF が System OFF でも動いている（25 §2）ので、時計は動き続ける。
- **PORF / VLF の扱い（33）は変わらない。** 電池を抜く / U5 が落ちる事象で時刻が失われる点は 1.8 V 構成と同じ。
- プルアップ電流はローの間だけ流れる（3 V / 10 kΩ = 300 µA、1.8 V のとき 180 µA）。I²C は日に数回の短い転送なので平均は無視できる。
- **この案の条件**: キットの側面 14 接点の 3V3 が、キャリア側へ給電を **出力**できること（25 は 3V3 を「出力」と記載。**フォーラムの 450 µA の報告は 3V3 へ給電する案**で、本案は逆向きで該当しない）。
- 却下した代案: TXS0102（B 側 2.3 V、§3）、ディスクリート FET（部品点数と、1.8 V 側ゲートの Vth 余裕が未確認）。**この案が崩れる条件**: RTC を 1.8 V のレールで動かさなければならない理由（例: RTC のバックアップ電池を別に持つ）が出た場合。そのときは TXS0102 ではなく **PCA9306 級**（要データシート）か FET を再検討する。

## 8. 決めてほしいこと（issue #22）

1. **push-pull の第一候補は TXU（0204 + 0304）でよいか。** 理由: ICC が 1 桁低く、個数が 1 個少ない。弱点は速度（Schmitt 入力で遅い見込み。SPI の上限は実測、10 MHz 前後と仮置き）と BQA 型の入手性。NOR を 10 MHz 超で動かす必要があるなら AXC に倒す。
2. **RTC を nRF 側のレール（3V3）に置く**（§5）。25 / 36 / 24 の「周辺 = 1.8 V」の記述を、RV-3032 だけ例外にしてよいか。
3. キットの 3V3 接点を「キャリアへの出力」として使うことの確認（Phase 0 で U5 の 3V3 をプローブして、電池追従と負荷への耐性を測る）。
