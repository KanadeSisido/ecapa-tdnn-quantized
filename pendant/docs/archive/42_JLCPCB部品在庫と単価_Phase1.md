## 4. 実装費（取得できなかったもの）

- **JLCPCB の PCBA 見積ツールは基板ファイルが要る。** `hw/phase1-carrier/` は空の 2 層基板で、BOM / CPL / Gerber が無い。**Phase 1 の基板設計（回路図 + レイアウト）の後で見積を取る**。
- 追加でかかるもの（金額は**未確認**）: Extended 部品は**種類ごとに手数料**がかかる（本書の 4 部品はすべて Extended）。PCBA の段取り費、ステンシル、テスト。
- 取り寄せ（Mouser / DigiKey / Farnell）の価格は、T5838 の Farnell（DE）€1.96〜、element14（CN）CNY 17.67〜（Web 検索の断片、日付未記載）。**JLCPCB の方が在庫と価格の両方で現実的**。

## 5. 決めてほしいこと（issue #23）

1. **見積を取る前に Phase 1 の基板設計（回路図）を先に進めるか。** 実装費は基板ファイルが無いと出せない。FW 側の用意（本リポジトリ）はできているので、**KiCad の回路図を書く作業が次の律速**。
2. TPS62840 の代替（TPS62843 系など、1.8 V 固定出力の品）は、本書では候補化していない（JLCPCB の TPS62840 は在庫 6,537 個で、代替は不要）。
