## 0. 結論

- 外部AIの 15 項目のうち **約 10 項目は既に 36〜41 に書いてあり**、検証しても数値は一致した（ピン再配置、TXU 2 個、RTC の 3V3 側、reservoir 100〜470 µF、BQ25505 の 3.673 V・0.1 %、stack-up の要旨、NOR の寄与）。新しい設計判断は **物理 privacy latch** だけ。
- 外部AIの記述のうち **そのままは採れない点が 4 つ**ある（§2）: ① キット版に電池分圧器は要らない、② 「XIAO を沈めて −1 mm」は 41 の表に既に入っていて二重計上、③ 「TXU の入力に 1 MΩ の pull を置く」は TXU に 5 MΩ の内蔵 pull-down があり、置くなら **nRF 側の入力**、④ 逆流防止を「必須」とするのは過大（USB を挿せない運用なら保険）。
- **Phase 1 キャリアには電池電圧を測るためのアナログ入力ピンが 1 本も空いていない**（§3.1）。これは外部AIも 36 も触れていない。回路図を描く前に決める必要がある。
- **privacy latch は採る価値がある**が、「Mic の VDD を切るだけ」では足りないことを T5838 の絶対最大定格で確認した（§4）。キット版は TXU0204 の B 側電源を latch の先に繋ぐだけで解決する。

| 外部AIの記述 | 確認した事実 | 扱い |

## 3. 各項目の調査

### 3.1 電池電圧センシング

必要性: 30 §2 の 4 段階と、38 の「NOR 消去は電池電圧のゲート」が電池電圧に依存する。**測れなければ 30 の状態機械は動かせない**。

方式の比較（電池側の電力は 39 の p = 0.25 で 363 µW、p = 0.4 で 551 µW が基準）:

| 方式 | 常時の電流 | 追加ピン | 使える場所 |
|---|---:|---:|---|
| 100 kΩ + 100 kΩ の常時接続 | 15 µA = 45 µW（p = 0.25 の 12 %。年で 0.39 Wh = 2.9 Wh の 13.6 %）| 1（AIN）| **採らない** |
| 分圧器 + 測定時だけ FET で接続 | リーク（FET）のみ | 2（AIN + EN）| ピンに余裕がある場合 |
| 数 MΩ の常時分圧 | 約 0.3〜0.5 µA | 1（AIN）| SAADC のサンプリング時間と入力容量の確認が要る（未確認）|
| **SAADC の内部入力 `Vdd`** | **0** | **0** | **キット版**（VDD ≒ 電池。下記）|

- nRF54L15 PS v1.0: `CH[n].PSELP.INTERNAL` に `Vdd = 2`（VDD に接続）がある。Zephyr では `NRF_SAADC_VDD`。DevZone には VDD を gain 1 で測って 0.9 V 付近になったという投稿があり、**gain は 1/4 を使う**（0.9 V ÷ 0.25 = 3.6 V が満点）。要実機確認。
- キット版: nRF の VDD は U5（TPS628438）の出力で、CR2477 の範囲（3.3 V 以下）では常に 100 % モード。VDD ≒ 電池 − 負荷 × 約 0.4 Ω（37 §2、38 §2）で、30 のしきい値（2.60 / 2.40 / 2.25 V）の判定には十分。**ハードウェアの追加なし**。
- **Phase 1 キャリアは nRF の VDD が 1.8 V の固定 rail**（L1 を外して TPS62840 から給電、23 §3.1）なので `Vdd` では電池を測れない。**アナログ入力は P1.04〜P1.07 と P1.11〜P1.14 だけ**（PS のピン表）。XIAO の側面で出ているのは D0〜D3（P1.04〜P1.07）と D5（P1.11）で、**どれも PDM / WAKE / ボタン / SCL で使用済み**。P1.12〜P1.14 は XIAO 内部（マイクと電池の ADC）で外へ出ない。D11 / D12（P0.03 / P0.04）と D13〜D15（P2）はアナログ入力ではない。

**決めてほしいこと（Phase 1）:** 電池の分圧器の出力を、どのピンに共有するか。案:
1. **D3（ボタン）とジャンパで切り替える**（Phase 1 は評価基板なので前面ボタンの機能を犠牲にできる。電池測定の試験のときだけ分圧器側へ）。**推奨**。
2. 電池電圧は Phase 1 ではオシロ / テスターで読み、FW へは固定値を注入する（30 の状態機械を実機で回さない。30 §5 #2 が言う「入れない場合は動かせない」に該当）。
3. D0〜D5 のどれかを諦める（Phase 1 の測定項目が減る）。

### 3.2 reservoir（100 / 220 / 470 µF）

- 38 の結論（短いパルスは reservoir、消去は電圧ゲート）と外部AIの整理は一致する。**採用済み。**
- **38 が書いていない注意（エンジニアリング判断、データシート未確認）:** 220〜470 µF のタンタル / 導電性高分子は **漏れ電流が µA〜数十 µA に達しうる**（仕様上限は容量 × 電圧の 0.1 倍級のものがある。実測 typ は小さい）。平均 363〜551 µW（約 120〜180 µA）に対し、10 µA は 2〜8 %。**漏れの小さい MLCC（100 µF 級、DC バイアスで実効容量が下がる）を第一候補、タンタルは漏れを実測してから**とする。Phase 1 の測定項目に「reservoir 交換時の rail 電流差」を足す。

### 3.3 計測用の 0 Ω とテストポイント

- 23 §3.1 の R_BAT / R_MAIN / R_MIC / R_FLASH / R_RTC と 05 の TP 群で、外部AIの「最低」はほぼ満たしている。
- **追加:** `TP_NOR`（R_FLASH の先）、TPS62840 の **入力側 R_BAT は既出、出力側（1V8_MAIN の根元）の 0 Ω**、reservoir の両端。Phase 1 は製品より測定を優先する（05 の考え方）。

### 3.4 CR2477 → XIAO 5V の逆流防止（キット版のみ）

- USB を挿すと D4 経由で 5V ピンから電池へ電流が入る（36 §4）。Schottky は成立するが、**U5 の VIN 最小 1.8 V** に対し、38 の R = 40 Ω・8 mA のパルスで必要な電池電圧は、ダイオード無し 2.12 V、**Schottky（0.25 V と仮置き）で 2.37 V**（周辺 rail 側の 2.18 V より **0.19 V 高く**、nRF 側がシステムの下限を決める）。この 0.19 V の間に残る電池容量の割合は未確認（膝の手前で小さいはず）。
- 候補: **TI LM66100**（ideal diode、VIN 1.5〜5.5 V、IQ 150 nA typ、RON 141 mΩ typ @ 1.8 V、逆流を遮断）。1 µA 未満の IQ で降下はほぼ 0。価格・JLCPCB 在庫は未確認（42 の表に無い）。
- 判定: footprint を置き、Schottky / ideal diode / 0 Ω を選べるようにする。**運用で USB を挿せない構造なら実装しない選択肢を残す。**

### 3.5 筐体の厚み（41）

- **XIAO の実測（ユーザー、2026-10-14）: 平らな部分 3.33 mm、USB-C 部 4.44 mm。** 41 の仮定（想定 2.2 mm、最大 3.0 mm）を超えたので、41 §4 を更新した。**全層の合計は最小 14.9 mm、想定 16.8 mm、最大 19.7 mm**（実測前は 13.4 / 15.7 / 19.4）。
- 外部AIの「15.7 − 1 − 1 = 13.7 mm」は、(a) 沈め込みの −1 mm が 41 の表に既に入っている二重計上、(b) 接点の最小 1.0 mm が下限、の 2 点で成り立たなかった。実測でさらに悪化した。
- **したがって、外部AIの「前面ボタンは最後まで残す」順序は成り立たなくなった。** 前面ボタン層（1.2〜1.6 mm）を残したままでは、全層が最小でも 14.9 mm で 15 mm にほぼ届かない。ボタンを除いても想定 15.2 mm、最小 13.7 mm。
- 選択肢（41 §4 末尾）:
  1. ボタンを側面 / 背面へ移し、全層を最小に寄せる（15 mm 以内に入る見込みは低い。最小で 13.7 mm、想定 15.2 mm）。
  2. 目標の厚さを 16〜17 mm に緩める（前面ボタンを維持）。
  3. **平面で並べる**: 内径 約 Ø45.9 mm（外径 約 Ø48 mm）にすれば、XIAO の厚さが全厚に加わらない（約 10〜12 mm）。直径が増える。
  4. USB-C 部（4.44 mm）を電池の外周より外へ出す（全厚が 1.1 mm 増える部分を避ける）。**採用（ユーザー、2026-10-14。41 §8）。** 1 / 2 / 3 は未決で、これだけでは想定 16.8 mm のまま。XIAO を USB-C 側へずらすとアンテナ側が電池の中心寄りに来る点に注意（41 §8）。
- AirTag 互換は XIAO 版では成立しない（最小 13.3 mm）。41 §7 #1 と同じ結論。

### 3.6 Mic の変更・NOR の置き換え

- **今は変えない**に同意。34 の 7 場面の ASR 実験（#19、#20）が先。
- 39 の結論（16 kbps を標準にするだけで p の上限が 0.21 → 0.38 に動く、HW 変更なし）が最初の手。NOR → NAND は価格と在庫（20）が障害。**新しい情報は無い。**

## 4. 物理 privacy latch（新規）

### 4.1 要求

- スイッチが PRIVATE のとき、**FW が何をしても**マイクは音を拾えない。
- スイッチの状態を GPIO で読まない（キット版は GPIO が 11 本で余裕 0、36）。

### 4.2 「Mic の VDD を切るだけ」では足りない

T5838 Rev 1.0 の Table 8: **デジタルピンの入力電圧は −0.3 V 〜 VDD + 0.3 V または 1.98 V の小さい方**。VDD が 0 V のとき、CLK / THSEL に 1.8 V を入れると **絶対最大定格を超え**、ESD ダイオード経由でマイクの VDD ノードが持ち上がる（部分給電）。**FW が壊れて CLK を出し続ければ、スイッチを切ってもマイクが部分的に動くおそれがある。** 外部AIの指摘（back-power）は正しい。

### 4.3 キット版: TXU0204 の B 側電源を latch の先に繋ぐ

37 の採用案（TXU0204 + TXU0304）は、信号の数が自然に 2 グループへ割れる:

| 変換 IC | 方向（nRF → 周辺 / 周辺 → nRF）| 割り当て |
|---|---|---|
| TXU0204 | 2 / 2（A1、A2 が入力、A3Y、A4Y が出力）| **マイク**: CLK、THSEL / DIN、WAKE |
| TXU0304 | 3 / 1 | **NOR**: SCK、MOSI、CS / MISO |

- TXU0204 の **VCCB を latch の先（MIC_1V8）に繋ぐ**。TXU の仕様: **どちらかの電源が 100 mV 未満または浮きのとき、全出力が Hi-Z（Ioff-float、§9.3.5）**。latch を切ると T5838 の VDD と TXU0204 の B 側が同時に落ち、**CLK / THSEL を駆動するものが無くなる**。部品は増えず、GPIO も使わない。
- TXU の ICCA（VCCB が浮いたとき）は max 1.5 µA（25 ℃）/ 7 µA（85 ℃）/ 15 µA（125 ℃）（ICC 表）。通常運転は 37 の見積りどおり。**PRIVATE 中は録音しないので、この増分は平均電力に効かない。**
- Hi-Z になった TXU0204 の出力（DIN → nRF、WAKE → nRF）は **nRF 側で浮く**。**nRF 側の入力に 1 MΩ 級の pull-down（または nRF 内蔵 pull-down）を置く。** これが外部AIの「1 MΩ 級 pull」の正しい置き場所。T5838 の DATA ピンに外部の pull を付けるのは禁止（§6 末尾の注意）だが、TXU の B 側入力の内蔵 5 MΩ は既に付いている（DATA の保持は 10 pF 級・CLK 768 kHz で 1〜2 % の減衰で、実用上は問題ない見込み。要実機）。
- 「入力は電源を浮かせる前に Low にしておくこと」（TXU §9.3.5）。latch を切る瞬間に CLK が High だと一瞬流れる。**FW は意識できないので、A 側の入力（CLK、THSEL）に内蔵 pull-down がある点と、ICC 表の Ioff-float の上限（±1.5〜2.5 µA）で許容できるかを Phase 1 で確認する。**

### 4.4 Premium / Phase 4（TXU 無し、nRF が 1.8 V で直結）

- TXU の代わりに、**電源を latch の先から取る 1.8 V のバッファ（Ioff 対応品）を CLK / THSEL に 1 段入れる**か、アナログスイッチで切る。
- 抵抗を直列に入れるだけの案は、電流を制限するだけで **絶対最大定格の逸脱は残る**ので採らない。
- 具体的な部品は未選定。Premium は後回しでよい。

### 4.5 Phase 1 キャリア

- Phase 1 は nRF が 1.8 V で T5838 に直結（TXU 無し）。**R_MIC（0 Ω）を、スイッチまたは 2 ピンのジャンパにできる footprint にする。**
- **試験**: R_MIC を開放し、CLK を回したまま、**マイクの VDD ノード（TP_MIC）の電圧と DATA の動き**を見る。これで 4.2 の懸念が実機で確認でき、4.4 のバッファが要るかが決まる。追加部品は不要。

### 4.6 FW への影響（外部AIの記述に無い）

- T5838 の AAD の設定（THSEL の 1 線書込み）は **電源を入れるたびにアンロックから必要**（34 §3）。latch を戻した瞬間にマイクは初期状態（AAD 無効）に戻るが、**FW は latch の状態を読めない**。
- 対策案: **FW が一定の周期（例: 1 分）でマイクを起こして AAD を設定し直す**。1 回 10 ms × 120 µA × 1.8 V を 60 s ごとなら **約 0.04 µW**（無視できる）。または、PDM の内容が **定数（全 0 / 全 1）のとき「マイク無電源」とみなし**、event レコード（28）に「privacy ON」を記録する（GPIO 不要、要実機）。
- latch を切っている間の欠落は、既存の欠落記録（22 §3.1）に載せる。

### 4.7 機構（未決）

- latch の電流は 20〜120 µA、1.8 V と小さい。**乾式接点（金メッキ）の小型スライドスイッチ**が候補。
- ただし **防水の前面全面ボタン / 膜防水（26）に対し、可動の外部スイッチは封止の穴になる**。磁気式（リードスイッチ等）で筐体内に閉じ込める案は、ゼロ電力で封止も保てる。**どちらも未検討**（07、26 に戻る）。
- 状態が一目で分かる表示（スライドの色など）を機構側で作る。

## 5. 決めてほしいこと

1. **privacy latch を採るか。** 採る場合、**キット版は TXU0204 = マイク、TXU0304 = NOR の分担と、TXU0204 の VCCB を latch の先に置く構成**で進めてよいか（§4.3）。機構（スライド / 磁気）は別途。
2. **Phase 1 キャリアの電池電圧のピン**: D3 とジャンパで共有（推奨）、または実機の状態機械を諦めるか（§3.1）。
3. **キット版の電池電圧は SAADC の `Vdd` で測る**（分圧器なし）。Phase 0 の XIAO で、gain 1/4 の値が電池電圧と合うかを先に確認してよいか。
4. 逆流防止は footprint（Schottky / LM66100 / 0 Ω）を置いて、実装は運用次第でよいか（§3.4）。
5. 37 §4 の pull の記述を、本書 §2 のとおり直してよいか。

既出で決定待ちのもの: 37 §8（TXU の採否、RTC を 3V3 側へ）、40 §6（OV を 3.673 V・0.1 % 抵抗に）、41 §7（AirTag 互換を諦める、ボタン移動）。
