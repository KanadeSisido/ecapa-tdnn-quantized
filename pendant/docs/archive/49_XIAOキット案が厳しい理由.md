# 49. XIAO を同梱するキット案が厳しい理由

Status: **整理（2026-10-15）。結論: XIAO は開発専用にして、キット案はやめた（48 §7.4 X1）。dogfooding の本筋は Raytac AN54LQ-15（X2）。** ユーザーは今も、XIAO nRF54L15 をキットで載せる案（[24](../docs/archive/24_XIAO低背着脱キャリア.md)）を残したいと考えている。この文書は、なぜそれが厳しいのか、そして何が分かればこの案を生かせるのかを並べる。規制の部分は web 調査（[48](./48_前提の確定_2026-10-14.md) §7.1〜7.2）で読んだ内容で、**法的な確定ではない**。SIG・Seeed・試験所への問い合わせ（[46](../docs/plan/compliance.md) §2）の回答で変わりうる。

## 1. 要点

- XIAO キットの最大の狙いは、**需要を確かめる前に、SIG と認証の固定費を払わずに済ませる**ことだった（24 の冒頭）。
- 調べた範囲では、**この狙いが日本以外では成り立たない可能性が高い**（§2）。
- 狙いが外れると、XIAO を使うことによる不利（§3〜§5）だけが残る。具体的には、厚さ、3.3 V 系とレベル変換、PC での書込み、価格。
- ただし **日本だけで売る場合は、規制の面ではいちばん軽い**。§6 の条件がそろえば、この案は残せる。

## 2. 規制とライセンス（いちばん大きい理由）

| 対象 | 内容 | 出典（48 §7.1〜7.2） | 確度 |
|---|---|---|---|
| **Bluetooth SIG** | QPRD v5（2026-04-21）は、自社の名前で売るものを Product と定義する（§1.1）。他社がその Product の qualification を代わりに済ませることはできない（§2）。FAQ が免除するのは、**自社ブランドを付けない再販業者だけ**。XIAO を未改造の別部品にしても、**「lifeOS Pendant」として売れば自社の Bluetooth 製品とみなされ、Declaration ID（約 $12k）が要る**可能性が高い | QPRD v5、SIG FAQ | 要書面確認（46 §2.2 Q1） |
| **EU（CE / RED）** | Guide §1.7.4.10 では、**説明どおりに組み立てた状態の適合責任はキットの製造者にある**。§1.7.4.11 では RF モジュールそのものが無線機器になる。無線なしの carrier だけを売る場合も、carrier は EMC 指令の対象になる（EMC Guide 2025 草案 §1.5.3）。RoHS、WEEE、電池規則、GPSR は残る | EU RED Guide | 要試験所確認（46 §2.4 Q5） |
| **米国（FCC）** | §15.3(p) はキットを「別の部品を足して完成させるもの」も含めて定義している。§15.23 の自作機器の免除はキットを除外している。**組み上がった機器には Part 15 がかかる**。さらに、XIAO の FCC 認証の種類（モジュール認証か、身に付ける用途の条件はあるか）が分かっていない。一般的なモジュールの grant には「OEM が組み込む場合に限る」という条件がある | 47 CFR 15.3(p)、15.23、各 grant | XIAO の FCC は要確認（46 §2.3 Q1） |
| **英国** | CE の書類が使える。加えて PSTI（初期パスワードの禁止、脆弱性の窓口、サポート期間の明示） | UK RER、PSTI | — |
| **日本** | **XIAO の工事設計認証 217-252398（2025-07-24、Sense を含む）は検索で確認した。** carrier は無線設備ではないので、未改造の技適品を使えば適法。電波の面ではいちばん軽い | 総務省の検索 | 確認済み（画面の保存は担当者、46 §1） |

**結論:** 「XIAO を別に入れればライセンス料も認証も要らない」は、**日本の電波法でしか成り立たない見込み**。海外でも売るなら（48 A4）、SIG と CE と FCC の費用はキットでもかかる。費用がかかるなら、後で述べる §3〜§5 の不利を背負ってまで XIAO を使う理由が薄くなる。

## 3. 書込みの UX

- 購入者が FW を書くには、**PC と pyOCD 相当の書込みツールが要る**。XIAO の USB は SAMD11 の CMSIS-DAP / UART ブリッジで、ドラッグ＆ドロップの書込み（MSC / UF2）は無い（48 §7.1）。SAMD11 の FW を入れ替えて MSC にする案は、16 KB の flash に収まるかが厳しく、既存の実装も見つからない。
- **iOS からは USB で書けない**（WebUSB が無く、CMSIS-DAP の経路も無い）。Android は WebUSB か USB host で書ける見込みだが、nRF54L15 用の書込みの処理を自作する必要がある。
- **UF2（USB ドライブにファイルをコピーするだけで書ける方式）は、nRF54L15 では使えない。** UF2 は、MCU 自身の USB でマスストレージとして見せるブートローダの機能。nRF52840 には USB があるので、XIAO nRF52840 では標準で UF2 が使える。nRF54L15 には USB が無く、XIAO nRF54L15 の USB は SAMD11 のブリッジにつながっている。UF2 を使うには、SAMD11 側に MSC を実装する必要がある（上の 16 KB の問題）。
- 外部 AI の案（2026-10-15）から採るもの:
  1. **3 層構造。** 開発は SWD、製造時は SWD でブートローダと初期 FW を 1 回だけ書く、利用者は簡単な経路だけを使う。48 R2（出荷前に MCUboot、以降は BLE で DFU）と同じ形で、利用者の経路が UF2 の代わりに BLE DFU になる。
  2. **既存ボタンの長押しで更新・復旧モードに入る。** 例: 起動時に前面ボタンを押したままなら、MCUboot の復旧モードに入る。
  3. **XIAO キットで PC を使う場合の書込みは、ブラウザの WebSerial と MCUboot serial recovery（UART 経由の MCUmgr）で作れる見込み。** SAMD11 の UART ブリッジを使う。ツールのインストールが要らない。MCUboot を先に書いておく必要があり（製造時の 1 回）、未検証。
- 「出荷前に MCUboot を書き、以降は BLE で DFU」（48 R2）にすると UX は良くなる。ただしそれは **当方が XIAO に書き込んで出荷する**ことになり、24 の「未書込みの別部品」という前提（SIG の扱いを軽くする狙い）と両立しない。

## 4. 電力と電圧

- 無改造の XIAO は **3.3 V 系で動く**ので、1.8 V の周辺（T5838、NAND）との間にレベル変換が要る（[25](../docs/archive/25_XIAO無改造とレベル変換コスト.md)、[37](../docs/archive/37_レベル変換IC比較.md)）。TXU0204 + TXU0304 で最大 2.5〜12 µA（25〜125 ℃）。Standard の平均（約 114 µA）に対して **4〜10 %**。部品は 2 個増える。
- XIAO の降圧（TPS628438）は CR2477 では常に dropout になるので、**nRF の電源電圧が電池に追従して下がる**。変換 IC の電源も 3V3 に追従させる必要がある。動作の下限は nRF と変換 IC の両方で決まる。
- 電池は 5V ピンから入れる。XIAO の裏面の電池パッドには充電 IC（SGM40567）がつながっていて、CR2477 を充電してしまう恐れがあるので使えない。**USB と電池を同時につなげない手順**を、購入者に守ってもらう必要がある（24、45）。
- XIAO の基板上の部品（降圧の静止電流、Q1 の経路など）が待機電力にどれだけ足されるかは、**未測定**。
- 1.8 V で直接動かす（L1 を外して 3V3 ピンに 1.8 V を入れる、Phase 1 の方式）のは改造になる。キットでは使えない。

## 5. 厚さ・ピン数・価格

- **厚さ**（[41](../docs/spec/mechanical.md)、XIAO の実測は 3.33 mm、USB-C 部は 4.44 mm）: Standard は想定 16.8 mm（全層を最小にしても 14.9 mm）。ボタンを前面に残す（48 E2）なら 15 mm 以内に入らない。**AirTag 互換（中央 10〜12 mm）は成り立たない**（最小でも 13.3 mm）。
- **ピン**（[36](../docs/spec/board.md)）: 側面の 14 接点を **余りなし**で使う。電池電圧の測定（48 B4）や privacy latch（B5）を足す余裕がなく、ジャンパでの共有などの工夫が要る。
- **価格**: XIAO nRF54L15 Sense は ¥3,069（Switch Science）。素のモジュールは Raytac AN54LQ-15 が ¥990、u-blox NORA-B206 が ¥943（Mouser）。ただし素のモジュールは自分で実装する（完成品になる）前提の価格。

## 6. XIAO キット案を生かせる条件

次のどれかが成り立てば、XIAO キットは選べる。

1. **SIG が書面で「無線を含まないキットの売り手や、OSS FW の公開者は qualification の対象外」と回答する**（46 §2.2 Q1）。その場合は構成 B（無線なしの carrier を当方が売り、購入者が XIAO を別に買い、OSS の FW を自分で書く）が候補になる。
2. **まず日本だけで、メーカー層向けに少数を売る。** 電波の面は技適済みの XIAO で済む。SIG は 1 の回答が前提になる。海外は、完成品の認証（48 §7.2 ②）を取ってから。
3. **SIG と CE の費用を払う前提で、XIAO を「はんだ付けの要らない完成品の部品」として使う。** 規制の面ではモジュールと同じ扱いになる。ただし §3〜§5 の不利がそのまま残る。XIAO の FCC 認証の種類と、身に付ける用途の条件の確認が先（46 §2.3）。

どれも、**46 §2 の問い合わせの回答が出てから判断する**（48 R1 の保留と同じ）。その間も、XIAO は開発用（Phase 0 / Phase 1）として使い続ける。開発用としての XIAO の価値は、この文書の内容とは関係なく変わらない。
