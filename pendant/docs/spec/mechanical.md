# 筐体・防水・機構仕様

外装、前面ボタン、Solar-button の配線、防水・汗・腐食、内部配置、スタックアップ、製造ルートを定める。マイクの音響要件は [audio.md §3](./audio.md)、アンテナと RF の keep-out は [rf.md](./rf.md)、終端表示の機構は [terminal-indicator.md](./terminal-indicator.md)、電源の部品と電池は [power.md](./power.md)、基板のピンと測定点は [board.md](./board.md) が持つ。

確度の表記:

- **確定**: 設計の前提として動かさない。変えるときは設計変更として扱う。
- **方針**: 向きは決まっているが、数値や部品が決まっていない。
- **仮置き**: 実測や CAD で置き換える前提の値。

## §3 前面ボタン

前面全体を 1 つのボタンにする（確定）。ケースを貫通するスイッチ軸は作らない。外界との境界を 1 枚の膜にして、ボタン機構そのものには防水を要求しない。

### §3.1 Standard

```text
外側
 ↓
硬質フロントキャップ（外観・押下面）
 ↓
シリコン / TPE のダイヤフラム（防水境界・変位吸収）
 ↓
内部タクトスイッチ + ドーム（クリック感・電気接点）
 ↓
PCB
```

### §3.2 Premium（Solar-button）

太陽電池面全体が押下面。Solar パネルを曲げず、剛体の carrier ごと軸方向に平行移動させる。

```text
Solar carrier（剛体）── ストローク 0.2〜0.4 mm
 │
 ├─ 外周: シリコンの環状ダイヤフラム
 ├─ 中央: plunger → snap dome → PCB
 └─ housing 側: hard stop
```

- 外周の O-ring を擦らせる方式は採らない。摺動面が無い**薄いシリコンのダイヤフラムを曲げる**方式にする（汗・粉塵・摩耗に有利）。
- ボタンの検出は snap dome と GPIO で行う。Solar の電圧はボタン入力の代用にしない。
- Solar のどこを押しても carrier が傾かずに平行に動くよう、ガイドを作る。

### §3.3 共通の要求

| 項目 | 要求 |
|---|---|
| ストローク（Premium） | 0.2〜0.4 mm |
| 寿命 | 数万回の押下で亀裂が出ない |
| 材料 | シリコーンゴムが第一候補。汗・皮脂に耐える。硬度と肉厚は試作で force curve を測って決める |
| 反力 | 低い。ただし §4.4 の合計で評価する |
| hard stop | **housing 側で受ける。** 強く押したときの数十 N は、ダイヤフラム・spring contact・Solar 積層・PCB に入れない |

- ボタンの役割（押したときの動作）は [product.md](./product.md)、クリック音の扱いは [audio.md](./audio.md)。
- privacy latch を採る（機構はスライドか磁気式かを、筐体と一緒に決める）。可動の外部スイッチは封止の穴になる。筐体の内側に閉じ込める磁気式（リードスイッチなど）は、電力ゼロで封止も保てる。電気側は [security.md](./security.md)。

## §4 Solar-button の電気接続（Premium のみ）

Solar carrier は 0.2〜0.4 mm 動く。パネルから固定 PCB へ細線や FPC を直結すると、押すたびに配線が曲がる。導体・はんだ・配線が疲労し、button feel がばらつき、防汗シールと干渉する。

### §4.1 構成（方針）

金メッキの spring contact を 2 本、carrier 側の金メッキ pad へ PCB 側から押し当てる。押下中は接点が少し縮むだけで、導線は曲がらない。

```text
moving carrier（Solar panel + 金メッキ pad ×2）
        ▲ +pad          ▲ −pad
      spring contact  spring contact
─────────────────────────────── 固定 PCB
```

- パネルの lead は carrier の剛体部分（小型 FR4 の island か金属 insert）へ固定し、動かさない。lead が短い安価なパネルでも、lead を接着などで固定して carrier へ 1 回だけ接続する。
- 2 本の接点は plunger に対して左右対称か近い位置に置く。片側に寄せると押下時に反力が偏り、パネルが傾く。
- 接点は**密閉した空洞の内側**に置く。汗が直接入らないのが理想で、入った場合は金メッキで腐食に余裕を持たせる。

### §4.2 部品

| 候補 | 仕様 | 位置づけ |
|---|---|---|
| Harwin S7251-45R | SMT の spring contact、金メッキ、3.0 × 1.5 × 1.5 mm、自由高 1.5 mm、作動高 1.2 mm、positive stop 0.9 mm、1 A。接触抵抗 50 mΩ 最大級、製品により最大 10,000 回の嵌合 | 第一候補。https://www.harwin.com/products/S7251-45R |
| Mill-Max 0905 系 | pogo-pin 型、100k〜1M cycles（ストローク中間）。Harwin より大きく高価になりやすい | 耐久を優先する場合の比較候補。https://www.mill-max.com/products/discrete-spring-loaded-pins/surface-mount-spring-loaded-pin/0905/0905-0-15-20-75-14-11-0 |

- 電圧降下: 40 mA × 50 mΩ = 2 mV / 接点。2 接点で約 4 mV で、Solar の数 V に対して無視できる。

### §4.3 spring contact と動く FPC の比較

| | spring contact | 動く FPC |
|---|---|---|
| 長所 | ストロークに対して疲労しない。標準の SMT で組立が簡単。配線は 2 本だけ。carrier を取り外せる | 接触不良が無く、導通が明確 |
| 短所 | 接触抵抗。ばね力が button feel に入る。汗の侵入に注意 | 繰り返し曲げの設計、曲げ半径の管理、専用部品、位置依存、折れ・接着で寿命が変わる |

ストローク 0.2〜0.4 mm・2 線・40 mA 級では spring contact を採る。

### §4.4 button feel

spring contact はばねの一部として button の反力に入る。

```text
F_total = dome の力 + ダイヤフラムの力 + spring contact（+）の力 + spring contact（−）の力 + 摩擦
```

設計手順: ① snap dome 単体の force curve を測る → ② ダイヤフラムを足す → ③ spring contact 2 本を足す → ④ carrier の重さと摩擦を足す → ⑤ 指で押す位置を変えて評価する。

### §4.5 Solar 入力への影響

- 押下中に接触抵抗が変わる、または接点が bounce して Solar 入力が一瞬途切れる可能性がある。BQ25505 の入力コンデンサで短い瞬断が問題にならないように設計する（[power.md §3](./power.md)）。
- 試験（§10.3）: 押下 / 非押下の接触抵抗、中央 / 端の押下、1k / 10k / 50k 回のあと、人工汗のあと、振動のあと。発電量と電圧を記録する。

### §4.6 v1 の仕様

| 項目 | 値 | 確度 |
|---|---|---|
| carrier のストローク | 0.2〜0.4 mm | 方針 |
| carrier | 剛体 | 方針 |
| 電気接続 | 金メッキ spring contact × 2（Harwin S7251-45R 級） | 方針 |
| 配置 | 左右対称、密閉空洞の内側 | 方針 |
| 荷重 | housing の hard stop で受ける。snap dome は別部品 | 方針 |
| パネル lead | carrier へ固定して非可動にする | 方針 |
| 寿命の試験 | cycling + 人工汗 | 方針 |

## §5 防水・汗・腐食

### §5.1 要求

| 項目 | 内容 | 確度 |
|---|---|---|
| 環境 | 汗をかいた状態で数時間装着できる。小雨・飛沫で壊れない。シャワー・水泳は要求しない | 方針 |
| v1 の等級 | **IPX4 相当の splash 耐性**を必達にする | 方針 |
| その先 | IP65 を評価目標にし、構造が固まってから IP67 方向へ進める（ボタン押下状態を含めて評価） | 方針 |

- ケース単体の等級を、PCB・ボタン・音孔を足した製品の等級として書かない（既製ケースの値も同じ）。

### §5.2 侵入経路と対策

| 経路 | 対策 |
|---|---|
| マイクの音孔 | oleophobic な ePTFE の acoustic vent（§5.3） |
| 動くボタンの外周 | シリコンのダイヤフラム（§3） |
| ストラップ取付部 | 異種金属の腐食を避ける。RF 接点を使う場合は筐体の内側に置く（§5.8） |
| 電池の交換部・背面蓋 | ガスケット + 機械 stop（§5.4） |
| テストパッド・継ぎ目 | 開発中のみ露出。最終筐体では外から触れない位置にする |
| Solar の電気接点 | 密閉空洞の内側、金メッキ（§4） |

### §5.3 マイクの音孔と膜

- 音孔の構造: 小径の孔 → ePTFE acoustic vent → 短い空洞 → MEMS マイク。音響の要求と vent の仕様は [audio.md §3](./audio.md)（候補は GORE GAW334）。
- 防水を筐体の外形だけで解かない。**短い音響経路 + 認定済みの膜 + 封止したマイクのガスケット**で解く。膜を厚く、孔を細くすれば防水は楽になるが音質が落ちる。
- 筐体側で決める項目: 孔径、膜の有効面積、接着面積、結露・汗対策、膜まわりの接着剤が孔へ流れ込まない治具。
- 公式: https://www.gore.com/products/categories/portable-electronic-vents/acoustic-vents

### §5.4 電池蓋

- 背面蓋はねじ（または bayonet）で締め、周囲に gasket / O-ring を入れる。gasket の圧縮量は機械 stop で決める。
- 電池の接点は金またはニッケルのメッキ。
- 粘着だけで完全に封止すると交換できなくなる。v1 は、多少厚くなっても交換できることを優先する。
- 評価: 電池を交換したあとの再シールの再現性（§10.2）。

### §5.5 PCB のコンフォーマルコーティング（方針）

- メイン PCB はコーティングを前提にする。試作ではアクリル（rework しやすい）かウレタン（薬品・湿気に強い）が扱いやすい。シリコーンは柔軟で温度特性が良い。
- **塗らない場所**（マスク治具を用意する）:
  - マイクの音孔
  - アンテナの放射部と RF keep-out
  - spring contact の接触面
  - 電池の接点
  - SWD / テストパッド（開発中）
  - コネクタの嵌合部
  - 圧力 vent / 音響 vent の接着面

### §5.6 露出した銅を作らない

- 汗が届きうる場所に bare copper を置かない。ENIG か金メッキの接点にする。
- 露出する via は必要以上に置かない。はんだ接合を外気に直接さらさない。
- Solar の spring contact と、ストラップの RF 接点は金メッキにする。

### §5.7 内圧

密閉ケースは気温・高度・日射で内圧が変わる。ダイヤフラムやマイクの膜に差圧が掛かると、button feel の変化、gasket の応力、浸水の駆動力になる。

- 必要なら専用の pressure vent（GORE の portable electronics 向け。https://www.gore.com/products/pressure-vents-portable-electronics ）を追加する。
- Ø40 mm 級では vent の面積が惜しいので、先にマイクの acoustic vent が圧力の平衡を兼ねられるかを実測する。

### §5.8 ストラップ取付部

汗が溜まりやすい。金属のねじ・insert の異種金属腐食、ストラップ金具からの塩水の侵入、RF 接点がある場合の接触抵抗の増加に注意する。ストラップ側にアンテナを置く案を採る場合は、接点を筐体の内側に置き、外から汗が直接触れない labyrinth / シールを作る（[rf.md](./rf.md)）。

### §5.9 初号機の必須事項

- マイク: oleophobic な acoustic vent
- Solar-button: シリコンの環状ダイヤフラム
- 背面蓋: gasket
- PCB: コンフォーマルコーティング
- spring contact: 金メッキ
- 露出した銅なし
- 人工汗の試験（§10.1）と、汗のあとの RF・マイク・ボタン・Solar の再評価

## §6 開口部と内部配置

### §6.1 USB-C 部の位置（確定）

**USB-C 部は電池の外周より外側（環状の部分）へ出す。** USB-C 部が電池と重ならなければ、全厚は基板の平らな部分で決まる（USB-C 部は 1.11 mm 厚い）。CAD での配置は設計者が作る。

- 適用範囲: XIAO nRF54L15 を入れる筐体（USB-C 部の厚さ 4.44 mm、平らな部分 3.33 mm）。BC15M 基板は USB を前提にしない（nRF54L15 に USB が無く、書込みは SWD パッドと BLE DFU。[firmware.md](./firmware.md)）。USB-C など背の高い部品を載せる場合も、電池の外周より外側に置く。
- USB の開口をケースの外へ出さない（防水と UX の割り切り）。書込みと復旧はケースを閉じる前、またはケースを開けて行う（方針）。
- CAD で確認する項目（XIAO を入れる筐体）:
  1. USB-C 受け口の基板上の奥行き（未実測）。奥の端が電池の円の外にあること。
  2. モジュールを USB-C 側へずらすと、反対側（アンテナ側）が電池の中心寄りに来る。電池は金属なので RF に直結する。アンテナの位置と電池の距離を確認する（[rf.md](./rf.md)）。
  3. USB-C の先端（電池の中心から約 19 mm）が内径 Ø38〜40 に収まること。壁 1.0 mm・Ø40 なら余裕は約 1 mm。
  4. 側面の接点（XIAO の長辺沿い 14 接点）と、基板の切り欠き・電池の接点の干渉（XIAO を入れる場合のみ）。

### §6.2 状態表示窓（方針）

終端表示（[terminal-indicator.md §4](./terminal-indicator.md)）のために、小さな**常時見える窓**を開ける。通常時は赤が常に見える。

- 窓は防水シールを保つ。可動フラグは窓の内側に置き、窓を貫通する軸は作らない。
- 窓の周囲に輪郭かアイコンを印刷して、黒（終端）が「表示なし」と誤読されないようにする。
- 位置はマイクの音孔・前面ボタン・アンテナの keep-out と干渉させない。
- 暗所では見えない（自発光しない）ことは受け入れる。
- 赤を「録音中」の意味で説明・販売表示に書かない。

### §6.3 マイクの音孔の位置

音孔はアクセサリーや衣服に塞がれない位置に置く。位置は [audio.md §3](./audio.md) が決める。AirTag 互換を採る場合（§8）、側面はアクセサリーに掴まれやすく、前面中央の近傍・前面外周より内側・背面中央の近傍を優先する。

### §6.4 電池

Standard の CR2477 は背面から交換する（§5.4）。電池は金属なので、アンテナの位置と keep-out を [rf.md](./rf.md) と合わせて決める。電池位置によるアンテナのデチューンを §10.2 で確認する。

### §6.5 基板の固定

- 基板の XY 位置は、筐体のリブか基板の外形で決める。電気接点に位置決めを担当させない。
- Z 方向の保持は、上蓋のリブ、snap の爪、薄いエラストマーのパッドで行う。
- 基板は 1 枚で電池・モジュール・ボタン機構を支える。ボタンの荷重は housing の hard stop で受ける（§3.3）。

### §6.6 RF まわりの機械的な keep-out

- モジュールのアンテナ周辺に、基板の銅、電池、NAND、ケースの金属部品、Solar の配線、120 F、CR2032、金属のストラップ部品を置かない。keep-out を機構 CAD にも反映する（[rf.md](./rf.md)。Fanstel の図面で位置と寸法を確認する。BC15M の keep-out は footprint に入っている）。
- 部品単体の外形だけで収まったと判定しない。横置きの cap、CR2032、PCB、ボタンの移動量と hard stop、音響ポート、テストパッドへのアクセスを、同じ積層図に入れて干渉を確認する。
- 市販のアクセサリーに金属（キーリング、フレーム、カラビナ、磁石）がある場合は、装着状態の RF を実測する（§10.2）。

### §6.7 ストラップ・吊り部

- 吊り部に金属を使う場合は RF を評価する。AirTag 互換を採れば、本体に吊り金具を設けなくてよい（§8）。
- ネックストラップの引張強度は §10.2 で確認する。

## §7 スタックアップ

### §7.1 方法

1. 前面から背面へ層を並べ、最小 / 想定 / 最大の 3 列で厚さを置き、合計を出す。
2. 電池の厚さ以外は仮置きとして、ノギスの実測や部品選定で置き換える。
3. 平面の干渉は、内径（外径 − 壁 2 mm）の円に部品が入るかで見る。壁は 1.0 mm を仮置きにする。
4. 二重に数えない。モジュールを基板に沈める場合は、沈めた後の厚さを 1 層として入れる。
5. 合計を §2 の目標と比べる。感度の確認として、ボタン機構の厚さ ±1 mm は合計を ±1 mm 動かす。

### §7.2 部品の寸法

| 部品 | 寸法 | 出典・確度 |
|---|---|---|

### §7.4a 詰めた積層（AirTag 互換を狙う、CR2477、Ø31.9）

§7.4 の最小列は、電池の蓋と背面カバーを別の層に数え、6 面すべてに隙間を置いていた。Ø31.9 で中央 12 mm を狙うときは、次のように詰める（決定 E1、2026-10-15）。

- 背面カバーが電池の蓋を兼ね、接点ばねを内蔵する。電池の − 側は基板のパッドに直接当てる。
- 基板は 0.6 mm。
- 前面は薄い膜。タクトはモジュールの横（前面側）に置き、前面の厚さはモジュールの高さで決める（タクトはモジュールより低いものを選ぶ）。
- 隙間は 2 か所（前面側と背面側）。

| 層 | 最良 | 想定 | 根拠 |
|---|---:|---:|---|
| 前面の膜 | 0.5 | 0.6 | 仮置き |
| モジュール（タクトは横） | 1.9 | 1.9 | §7.2（Web の表記は 2.0） |
| 基板 | 0.6 | 0.6 | 仮置き |
| CR2477 | 7.3 | 7.7 | Jauch 7.70 +0 / −0.4（EEMB 7.9 は使わない） |
| 接点ばね（圧縮後） | 0.2 | 0.3 | 仮置き |
| 背面カバー（蓋を兼ねる） | 0.6 | 0.8 | 仮置き |
| 隙間（2 か所） | 0.2 | 0.4 | 仮置き |
| **合計** | **11.3** | **12.55** | |

- 想定で 12 mm を約 0.55 mm 超える。最良なら入る。**電池の厚さ公差（−0.4 mm）とモジュールの高さ（1.9〜2.0）で決まる際どい値。**
- 削る順: ① モジュールの高さを実物で確認する（図面の 1.9 mm。Web の 2.0 mm なら +0.1）。② 背面カバーと接点を一体にして 0.6 mm にする。③ 前面の膜を 0.5 mm にする。④ Jauch の 7.70 mm 品に限る。
- 両面実装（タクトを裏側へ）や基板を 2 枚に分ける案は、Ø31.9 では効かない。裏側は電池（Ø24.5）が占め、電池の周りの輪は幅約 2.7 mm しかない。2 枚に分けると基板 1 枚分とコネクタの分、厚くなる。
- **RF の注意:** Ø31.9 ではモジュールが電池の真上に来るので、PCB アンテナ（シールドから先の約 3.6 mm）が電池の金属缶に重なる。アンテナの端を電池の外へ出す向きにし、装着状態の RSSI を実測する（[rf.md](./rf.md)）。
- それでも 12 mm に入らない場合は、AirTag 互換をやめるか、CR2450（5.0 mm、約 620 mAh。想定 9.8 mm、電池寿命は約 7〜8 か月）に変えるかを決め直す。

### §7.6a 11 月デモの薄型 MJF 案（2026-10-27）

**丸形 PA12 MJF** で、前面の縁、Solar carrier の受け・ガイド、hard stop、マイク孔、固定部を設計する。MJF の PA12 は光透過窓として扱わず、前面は開口を作り、別体の透明な薄板と Solar を剛体 carrier に保持して一緒に押す。全体が 0.2〜0.4 mm 動いても Solar 自体は曲げず、外周のダイヤフラムと housing 側の stop で動きを制限する。透明板、膜、端子の保持方法は未確定。太陽電池を隠す装飾にはしない。ソーラーと蓄電器を通常電源、ボタン電池を非常用とし、USB 給電・充電は設けない。公称 φ36 mm のパネルが外径を決めるため、基板と非常用電池の小型化は優先しない。SMD は表面にまとめ、電池ホルダー本体は裏面から挿すスルーホール品とし、表面から手はんだ付けする。裏面は裸のテストパッドも許容する。非常用電池は CR2032 × 1、24 時間の動作を目標とする。

電池ホルダーは [CH005-2032LF](https://akizukidenshi.com/catalog/g/g108967/) を第一評価候補とする。ユーザー指示により、表示高さ 5.4 mm のホルダーと最大本体径 9.0 mm の Vina 30 F は、どちらも **PCB 裏面側に横並び**で配置し、スルーホールの足を表面側から手はんだ付けする。両者の高さを足す必要はなく、裏面側の部品高さは最大約 9 mm。板厚 0.6 mm を合わせると約 9.6 mm だが、これは Solar・表面 SMD・筐体・固定・絶縁余裕を含まないため完成厚の保証ではない。**完成厚 10 mm を目標**とし、表面部品や Solar の位置により必要な最大積層を 3D と現物で確認する。ホルダーの足が表面ではんだ付けでき、背面カバーを開けて電池を交換できる構造にする。前回の 15 mm は両部品を PCB の反対側に置いた場合の仮定で、現在案には適用しない。

現 PCB ドラフトは φ39 mm のため、旧例の内径 38 mm には入らない。仮に周囲の壁を各 1 mm とすれば外径は少なくとも約 41 mm になり、クリアランス・固定部・公差は別途必要。PCB の φ39 mm は仮置きであり、MJF 筐体の寸法・パネルとの同心配置を確定する。

前面の第一評価品は [uxcell φ36 mm 丸型セル](https://www.amazon.co.jp/dp/B0H5MJDDX8) 1 枚。厚さ、外形公差、リード・封止を含む実寸と電気特性は未確認。外径 40 mm・壁 1 mm とした内径 38 mm に、公称径だけなら直径方向で 2 mm の差があるが、支持・シール・成形公差・配線を含めて成立するとは限らない。旧比較品 [KXOB121K04TF](https://anysolar.biz/KXOB121K04TF-datasheet/) は 23 × 25 × 1.2 ± 0.3 mm の四角形であり、その厚さを uxcell に流用しない。前面の見た目と実際の発電量は現物で確認する。

透明部の加工を減らすため、既製の丸い時計用風防を MJF の受けに載せる案を比較する。たとえば [φ36 mm・厚さ 1 mm の平ガラスの流通例](https://store.shopping.yahoo.co.jp/n-style/mg001-10-31.html) があるが、指定寸法の在庫・納期・実寸は未確認。公称 φ36 mm の風防と φ36 mm パネルでは外周の保持幅が得られないため、透明板を大きくする案を含め、公差と固定方法を CAD で確認する。ガラスは落下・押下時の破損を評価し、別材の透明板も比較する。ガラス自体を Solar に直接荷重を伝える支持にはしない。

薄さ優先の蓄電候補は [Eaton HSH0622-3R8226-R](https://www.eaton.com/us/en-us/skuPage.HSH0622-3R8226-R.html)、22 F、3.8 V、最大外形 **φ6.8 × 24 mm**。裏面のホルダーと並べる場合、部品高さは大きい方の約 6.8 mm を目安とし、PCB と表面部品・Solar・ケースは別途加味する。部品本体より長いリード、固定・絶縁・電池ホルダーと着脱領域、基板保持、マイク、RF keep-out を含む配置は未検証。入らなければ、[HSH0814-3R8256-R](https://www.eaton.com/us/en-us/skuPage.HSH0814-3R8256-R.html) 25 F、最大 φ8.5 × 15.5 mm を代替候補として比較する。[電源候補と性能条件](../plan/premium-power-circuit.md)。

秋葉原での調達を優先する候補として、[Vina 30 F](https://akizukidenshi.com/catalog/g/g116492/) は最大 **φ9.0 × 21.5 mm**。上の 22 F より径が 2.2 mm 大きいが、秋月秋葉原店に在庫表示を確認できた。[秋葉原優先の調達表と電気上の違い](../plan/premium-akihabara-parts.md)。

## §8 AirTag 互換（未決）

目的は、AirTag 用のホルダー、ペンダント、キーホルダー、粘着・車載・自転車のマウントを、外付けアクセサリーとして使えるようにし、ストラップ穴や金具などを自社で作らなくて済むようにすること。決めるのは設計者。

### §8.1 基準寸法

- AirTag: 直径 31.9 mm、厚さ 8.0 mm、重さは第 1 世代 11 g・第 2 世代 11.8 g、IP67。
- Apple 公式: 第 1 世代 https://support.apple.com/en-md/111847 、第 2 世代 https://support.apple.com/en-my/126203
- 公称の直径と厚さが合っても互換は保証されない。互換に効くのは、外周のエッジの R、表裏の曲率、外周数 mm の断面形状、最大厚の位置、表裏の非対称、アクセサリーが把持する位置、硬質ケースの爪の位置。**最終的には AirTag の実物を採寸する。**

### §8.2 形状の考え方

AirTag を完全にコピーするのではなく、**アクセサリーが把持する外周の領域だけを互換の形状にし、中央部だけを 10〜12 mm 級まで厚くする**。外周のリング幅や曲率は、実物の採寸や 3D スキャンの前に推定値で固定しない。CAD では外周のリング領域（AirTag の包絡）と中央の自由領域を別に管理する。

| 互換しやすい | 互換が厳しい |
|---|---|
| 外周だけを掴むリング型ホルダー | AirTag 全面を密着して包むハードケース |
| 前後面が大きく開いたキーホルダー | 前後面を挟む薄型ケース |
| ペンダントホルダー | 8.0 mm 厚を前提にしたスナップケース |
| 柔らかいシリコンリング | 財布用カードケースなど厚みの許容が小さいもの |
| 外周クランプ式のマウント | AirTag 表面に密着する防水ケース |
| 中央に逃げがある粘着・車載マウント | |

「AirTag accessory 互換」と言う場合は、互換の対象カテゴリを明示する。

### §8.3 lifeOS Pendant への影響

- 吊り金具・ストラップ穴・クリップを本体に持たせなくてよくなり、筐体を単純な防水円盤にできる（RF の面でも、本体に金属の吊り金具が要らない）。
- 前面ボタン: リング型なら装着したまま前面を押せる可能性がある。柔らかいシリコンケースが前面を覆う場合は、荷重・ストローク・誤操作を評価する。アクセサリーが前面を押して常時押下になる恐れがある。
- マイク: 全面を覆うアクセサリーでは音響性能を保証できない（§6.3）。
- 市販のアクセサリーの金属部品の影響は、装着状態の RSSI・BLE のスループット・パケットロス・接続距離で実測する。互換性と RF は別に評価する。

### §8.4 現在の数値（BC15M）

- 内径は 29.9 mm（壁 1.0 mm）。CR2477（Ø24.5）とモジュールは平面で並ばず、重ねる配置（Q）になる（§7.3）。
- Z は、Standard で最小 13.5 mm、想定 15.2〜15.3 mm（§7.4）。AirTag の 8.0 mm はもちろん、中央部 12 mm にも入らない。CR2477 の厚さ（7.3〜7.9 mm）だけで AirTag の 8.0 mm にほぼ達する。
- Premium（想定 19.6 mm、§7.6）はさらに厚い。
- モジュールの高さの差（1.9 と 2.0 mm）は、Q の合計を 0.1 mm 動かすだけで、結論は変わらない。

### §8.5 表示・商標

AirTag は Apple の製品名。商品名や広告で「AirTag そのもの」「Apple 純正」「対応」「互換」と読める表現をしない。外形の比較に使う場合は「AirTag と同程度のサイズ」までにして、商標表記を添える。**本案は既存アクセサリーとの機械的な互換を設計の目標にするもので、AirTag をブランドとして借りるものではない。** 販売前に商標と表示のルールを確認する（[plan/compliance.md](../plan/compliance.md)）。

### §8.6 判断の手順

1. **実物の採寸**: AirTag を 1 個入手し、ノギス・R ゲージ・写真測量 / 3D スキャンで外形を取る。アクセサリーが接触する外周断面を優先する。
2. **アクセサリーの分類**: 安価なアクセサリーを 5〜10 種類買う（シリコンリング、ハードリング、ペンダント型、キーホルダー型、粘着マウント、全面被覆ケースを含める）。各アクセサリーが把持する位置を確認する。
3. **ダミー筐体**（MJF / SLA）: ① AirTag と同寸のダミー、② Ø31.9・中央 10 mm 厚、③ Ø31.9・中央 12 mm 厚。アクセサリーの互換率を比べる。
4. **実機の統合**: モジュール・電池・NAND・マイクが入るか、前面ボタンの操作、マイクの音響、装着中の BLE、落下時の保持、首掛けの装着感。

最初の判断の門は、**どの範囲の外形を一致させれば何割のアクセサリーが使えるか**の実測。

## §9 製造ルート

### §9.1 数量ごとの経路（方針）

| 数量 | 第一候補 | 目的 |
|---:|---|---|
| 1〜5 | MJF PA12 | 機構・パッケージングの検証 |
| 5〜20 | MJF PA12 の継続 | 実使用の試験、防水構造の評価 |
| 10〜50 | MJF または真空注型 | 初期の頒布、外観の改善 |
| 50〜200 | 真空注型または既製ケースの OEM | 市場の検証 |
| 数百〜 | 射出成形 | 単価・品質・外観の最適化 |

数量の境界は固定値ではない。見積金額、表面仕上げ、歩留まり、組立工数で判断する。外観だけを理由に早期に金型へ投資せず、既製の量産品から防水・ボタン・電池蓋の機構を借りる。

### §9.2 少量試作: PA12 MJF

- JLC3DP または DMM.make の PA12 MJF を使う。用途は、外観・装着感、基板と電池のパッケージング、O-ring 溝、前面ボタンのストローク、吊り部の強度の確認。
- **MJF の造形物そのものを防水の境界とみなさない。** O-ring、シリコンのガスケット、面圧、ねじ締結 / クランプ、acoustic vent で止める。
- DMM.make の PA12 MJF は、支えられた壁の最小肉厚が 0.8 mm と案内されている。落下耐性・ねじボス・O-ring 溝を考え、主要な壁はこれより十分に厚くする。
- 参考: https://make.dmm.com/print/material/pa12-mjf/ 、https://jlc3dp.com/ 、https://support.make.dmm.com/hc/ja/articles/360040636614-MJF%E3%81%AE%E6%9C%80%E4%BD%8E%E9%99%90%E5%BF%85%E8%A6%81%E3%81%AA%E5%8E%9A%E3%81%BF%E3%82%92%E6%95%99%E3%81%88%E3%81%A6%E3%81%8F%E3%81%A0%E3%81%95%E3%81%84

### §9.3 10〜50 台: 真空注型

- 利点: MJF より外観を民生品に寄せやすい。マットや高光沢の塗装が使える。シリコン型は金型より安い。
- 欠点: シリコン型の寿命が有限。寸法の再現性が射出成形より弱い。防水のシール面は個体差を評価する。O-ring のシール面と嵌合部は必ず実測して工程能力を確認する。
- 参考: https://www.pcbway.com/oem/functional-prototype.html 、https://www.pcbway.com/rapid-prototyping/vacuum-casting/

### §9.4 数百台以上: 射出成形

- 材料: PC+ABS、PC、ASA。
- 専用化するもの: 上下ケース、前面ボタン、シリコン / TPE の防水膜、O-ring・ガスケット溝、モジュール・基板の固定、電池蓋、ストラップ取付部、マイクの音孔、必要なら状態表示の光学窓。
- 参考: https://www.rapiddirect.com/services/custom-enclosure/ 、https://www.pcbway.com/rapid-prototyping/

## §10 試験・評価

### §10.1 人工汗の試験

水没だけでなく人工汗で評価する。wearable の規格 IEC 63203-201-1 に perspiration resistance の試験がある。正式な認証ではなく、設計比較のための加速試験として使う。

1. 人工汗を外装と接合部に付ける。
2. 37 °C 付近で 24 h 保持する。
3. すすぎ、乾かす。
4. 動作を確認する。
5. これを複数サイクル繰り返す。

確認項目: 絶縁抵抗、Solar 接点の接触抵抗、ボタンの荷重、マイクの感度、BLE の RSSI、電池接点の接触抵抗、目視の腐食、ガスケットの膨潤。

### §10.2 評価項目

| 分類 | 項目 |
|---|---|
| 防水 | ボタン押下状態を含む浸水評価。電池交換後の再シールの再現性。汗・皮脂・石鹸水への耐性 |
| 音響 | 会話帯域での比較（1 kHz だけにしない）。vent の有無での周波数応答。衣服の擦過音。胸元に付けたときの指向性（方法は [audio.md](./audio.md)） |
| RF | ケースなし / あり の RSSI 比較。身体に密着したときの通信距離。金属調の塗装・リングの有無の比較。電池位置によるアンテナのデチューン。代表的なアクセサリー装着時の RSSI（§8） |
| 機械 | 1 m 級の落下。ネックストラップの引張。ボタンの寿命。電池交換の寿命 |
