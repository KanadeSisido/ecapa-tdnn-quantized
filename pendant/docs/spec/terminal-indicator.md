# 終端表示（電源断インジケータ）仕様

Standard と Premium の両方に載せる、赤⇄黒の機械式フラグの仕様。電源の電圧しきい値と状態機械は [power.md](./power.md)、筐体の窓と防水は [mechanical.md](./mechanical.md) が持つ。

確度の表記:

- **確定**: 設計の前提として動かさない。変えるときは設計変更として扱う。
- **方針**: 向きは決まっているが、数値や部品が決まっていない。
- **仮置き**: 実測で置き換える前提の値。

## §1 目的

ペンダントが **動作を続けられる状態か、通常のエネルギーと非常用電源の両方を使い切った状態か**を、電源が無くても一目でわかるようにする（確定）。

- 動作可能: フラグは見えていて **赤**。
- 使い切った: フラグは **黒** に変わり、すべての電源が失われても黒のまま。

したがって、これは LED ではなく、保持電流を必要としない。

読む人は 2 種類いる。

- **持ち主**: 黒は、ペンダントが記録を止めている可能性を示す（オフラインの代替表示。主な警告はスマホの通知、§12）。
- **周囲の人**: 赤は一般的な「REC」の慣習（赤 = オン）に沿い、黒はオフを意味する。

通常時を赤にする理由: 通常時が見えない（黒）設計だと、周囲の人に何も伝わらず、また「赤 = 録音中」と読まれるので「赤 = 故障」は誤解されやすい。代償は、持ち主が「赤がない」ことに気づく必要があり、積極的な警報より弱い点（§12）。

## §2 ユーザーから見える挙動（確定）

フラグは双安定の機械式 / 磁気式の 1 bit 表示。

| 状態 | フラグ |
|---|---|
| 出荷時（一度も電源を入れていない） | **黒** |
| エネルギーを与えたあと最初の起動に成功 | 赤に 1 回だけ反転 |
| 通常運転 | **赤** |
| Premium: 120 F の cap を使い切った | 赤のまま |
| Premium: CR2032 の非常用電源で運転中 | 赤のまま |
| Standard: 電池電圧が LOW / CRITICAL（[power.md](./power.md) §4.2） | 赤のまま |
| 電池（Premium は CR2032、Standard は CR2477）が終端の低電圧しきい値に到達 | 黒に 1 回だけ反転 |
| そのあと全電源が 0 V になる | 黒のまま、電力ゼロ |
| Premium: Solar / cap のエネルギーが十分に回復して起動する | 赤に 1 回だけ反転 |
| Standard: 電池を交換して、起動の門を越えて起動する | 赤に 1 回だけ反転 |

赤は「電源系が動作を続けられる」、黒は「使える電源を使い切った（または一度も電源が入っていない）ので、記録を止めている可能性がある」を意味する。

- 赤は「録音中」を**意味しない**。FW のハング、watchdog のループ、ring の満杯、マイクの無効化でも赤のままになる。表示・説明・販売表示で、赤が録音を保証するとは言わない（確定）。
- 一般的な残量計ではない。

## §3 原理

```text
              通常運転（赤）
                  │
   Premium: Solar → harvester → 120 F → system
   Standard: CR2477 → reservoir → system
                  │
   Premium: 120 F が空 → CR2032 の非常運転（赤のまま）
                  │
        電池が終端しきい値に到達
                  │
        ハードの supervisor が trip
                  │
        last-gasp のエネルギー reservoir
                  │
        磁気フラグへ TERMINAL パルス
                  │
                黒 ── 電力ゼロで保持
```

終端の反転は、nRF54L15、FW、BLE、NAND、main の system rail が生きていることに**依存してはならない**（確定）。

## §4 機構（方針）

カスタムの双安定磁気フラグ（micro flip-dot 型）。

- 見える部分は約 3〜5 mm
- 動作中は赤の面、終端は黒の面
- 可動部に永久磁石
- 2 つの安定位置を作る磁気または機械の detent
- 電磁パルスは状態遷移のときだけ使う。保持電流は流さない
- 筐体には、小さな**常時見える窓**を開ける（密閉。防水と位置は筐体の判断、[mechanical.md](./mechanical.md)）。窓の枠に輪郭またはアイコンを印刷し、黒の状態が「表示はあるが暗い」と読めるようにする（「表示がない」と読まれないため）。暗所ではフラグは発光しない。この制約は受け入れる。

電気的な目標（仮置き）:

| 項目 | 値 |
|---|---|
| 保持電力 | 0 W |
| 遷移ごとの目標エネルギー | < 10 mJ |
| 設計上の上限 | < 50 mJ |

実際のパルス電流、コイル抵抗、パルス幅、磁石の大きさ、形状は、試作の測定で決める。

## §5 終端電池の検出

終端の検出は、MCU から独立した常時動作のハード電圧 supervisor が行う（確定）。

基準の部品: **TI TPS3839** 級の超低 Iq の supervisor。supervisor の電流は sub-µA（150 nA 級が望ましい）。

| SKU | 検出する電池 | しきい値 |
|---|---|---|
| Premium | CR2032 | 公称 **2.325 V**（初期の固定設計値。確定） |
| Standard | CR2477 | 未確定（§13） |

- Premium の 2.325 V は、CR2032 の電源パス（[power.md](./power.md) §3）を前提にした値。基板のリリース前に、最終の CR2032 の負荷プロファイルと、電源パスの低電圧動作で確認する。変えるときは設計変更として扱う。
- Premium で BLACK を出すのは、CR2032 が終端の低電圧に達したときだけ。120 F の通常の枯渇や、CR2032 の非常運転では出さない。

## §6 last-gasp のエネルギー reservoir

supervisor が trip した瞬間に電池へ残っているエネルギーに頼らない（確定）。

```text
電池 ── 電流制限つきの充電 ──→ C_LAST_GASP
 │                              │
 └── 電圧 supervisor            │
        │                       │
        └── 終端イベント ────────┘
                                ▼
                         フラグのドライバ / コイル
```

要件:

- reservoir は通常の system 負荷から使えない（分離する）。
- 終端のときに、BLACK への遷移を少なくとも 1 回、確実に行える蓄積エネルギーを持つ。
- 使える蓄積エネルギーの目標は、**実測した最悪のフラグ遷移エネルギーの 2 倍以上**。設計の余裕は 3 倍以上が望ましい。
- 漏れは、電池の自己放電と非常時の負荷予算に対して無視できる大きさにする。

reservoir の容量は、アクチュエータの試作を測るまで決めない。目安として、10 mJ のパルスを約 2.3 V で出すには、変換と余裕の前で数 mF の容量が要る。

## §7 ドライバ（方針）

フラグは双方向。

- TERMINAL パルス → 黒
- RUN パルス → 赤

超小型の H ブリッジ IC か、ディスクリートの MOSFET ブリッジを使う。パルスのあとに意味のある静止電流を流さない。

- TERMINAL の経路は、MCU の関与なしに、独立した終端検出 / last-gasp 側から動かせること。
- RUN パルスは、system が起動し、遷移を保証できるだけのエネルギーがあるとき、MCU が指令してよい。

## §8 回復と初回の電源投入（方針）

- Solar が一瞬電圧を出しただけで赤に戻ってはならない。また、実際に起動していない system に赤を見せてはならない。
- RUN パルスは、電源が十分に回復し（Premium は主の 120 F が安全な restart しきい値を超え、Standard は起動の門を越え）、system の起動に成功してから出す。出荷品の初回の電源投入にも同じ規則を使う。

```text
黒を保持（出荷時、または終端）
   │
エネルギーが戻る / 初めて電源が入る
   │
main system が安全な restart 水準に到達
   │
起動成功 / power-good を確認
   │
RUN パルス
   ▼
赤
```

restart の電圧は、主の電源状態機械と一緒に決める（候補: Premium は 120 F の RECOVER 2.7 V、Standard は起動の門 2.70 V 仮置き。[power.md](./power.md) §3.2、§4.2）。RUN パルスに安全な cap 電圧は未確定（§11）。

## §9 失敗の考え方

黒への遷移は、通常の FW の障害ドメインの**外**に置く（確定）。次のどれかが既に失敗または shutdown していても、終端の黒を出せること。

- nRF54L15 の FW
- BLE
- NAND
- マイク系
- main の regulated rail
- 120 F の使える領域

完全に死んだ system は新しい仕事ができない。したがって黒のフラグは、**電気的に死ぬ直前**、予約したエネルギーが残っているうちにラッチし、そのあとは電力ゼロで機械的に保持する。

**失敗の向き**: last-gasp の遷移が失敗した、または衝撃でフラグが戻された場合、死んだペンダントでも赤を表示し続ける。したがって last-gasp の保証（§6）と、衝撃・誤反転への耐性（§11）は必須で、任意ではない。

## §10 確定事項

1. 終端の電源断を示す **LED の状態表示は持たない**。
2. **カスタムの双安定磁気 / 機械フラグ**を使う。
3. 通常の表示は **赤で常時見える**。終端は **黒**。
4. フラグは、通常のキャパの枯渇や、CR2032 の非常運転を示さない。
5. 黒にするのは、電池（Premium は CR2032、Standard は CR2477）が終端の低電圧に達したときだけ。
6. 黒は、電力ゼロで無期限に見え続ける。
7. 終端の検出は、MCU から独立したハードで行う。
8. 専用の last-gasp コンデンサの reservoir が、最後の TERMINAL パルスを保証する。
9. reservoir は通常の負荷から分離する。
10. 赤への RUN パルスは、エネルギーが回復したあと（または初回の電源投入）、main system が起動に成功してから出す。
11. 赤は「電源系が動作できる」を意味し、「録音中」を意味しない。表示は、それ以外を主張しない。
12. **Standard にも Premium にも載せる**。Standard は CR2477 用の last-gasp 回路を別に設計する。

## §11 試作で確認する項目

実装のパラメータで、アーキテクチャの問題ではない。

- フラグの直径と、見える部分の形状
- 永久磁石の寸法
- コイルの形状（PCB コイルか巻線か）
- TERMINAL / RUN に必要な電流とパルス幅
- 実測の遷移エネルギー
- 測定後の last-gasp の容量
- supervisor の正確な品番と suffix
- 実際の CR2032 の負荷での 2.325 V の検証
- RUN パルスに安全な cap 電圧
- 衝撃と誤反転への耐性
- 窓の密閉と視認性（位置、輪郭 / アイコン、暗所の制約）

## §12 持ち主への警告（この機構の外）

黒のフラグは、赤の警報より弱い持ち主向けの警告にすぎない。主な電池低下の警告は、**終端しきい値の前に出すスマホの通知**にする。Standard はスマホが必須の SKU（[product.md](./product.md)）。フラグは、スマホが近くにないときのオフライン代替。通知の経路は FW とアプリの設計に属する（テレメトリは [power.md](./power.md) §8）。

## §13 Standard の終端表示（CR2477）

機構、窓、ドライバ、last-gasp の考え方は Premium と同じ（§4〜§9）。違いは検出する電池だけで、回路を別に設計する（方針）。

- 検出する電池は CR2477。supervisor（TPS3839 級）のしきい値は、CR2477 の放電曲線とパルス降下の実測のあとで決める。Premium の 2.325 V は CR2032 用で、Standard には適用しない。
- Standard の電圧段階（[power.md](./power.md) §4.2）の TERMINAL（2.25 V、仮置き）は、FW が rail を安全に落とす段。ハードの trip は、MCU を介さず、同じ付近の電圧で動かす。2 つの順序は未確定。
- last-gasp コンデンサは電池から電流制限付きで充電し、通常の負荷から分離する（§6）。CR2477 は内部抵抗が高いので（[power.md](./power.md) §4.4）、充電の電流制限とパルスの降下を合わせて設計する。
- 電池を交換したあとの RUN パルスは、起動の門（2.70 V 仮置き）を越えて起動に成功してから出す（§8）。
